# Bachelorarbeit – Dimensionierungstool für Photovoltaik-, Batterie- und Wärmepumpensysteme

## Inhalt

Diese ZIP-Datei enthält den Quellcode und die zugehörigen Datengrundlagen des im Rahmen der Bachelorarbeit entwickelten Dimensionierungstools.

Enthalten sind:
- Python-Quellcode
- Wetterdatensätze
- Standardlastprofile
- Stations- und Metadaten
- Pflichtenhefte
- Weitere für die Ausführung benötigte Dateien

## Ausführung

Das Tool wurde in Python entwickelt und als Streamlit-Anwendung umgesetzt.

Start der Anwendung:

```bash
streamlit run app.py
```

## Hinweise

Für die Ausführung müssen sich alle enthaltenen Daten- und Eingabedateien in der vorgesehenen Ordnerstruktur befinden.
Die verwendeten Wetterdaten stammen von MeteoSchweiz und dienen als Grundlage für die Simulation.
